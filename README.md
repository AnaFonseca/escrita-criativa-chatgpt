# Como utilizar o ChatGPT no ensino das línguas

Recurso pedagógico autónomo de escrita e escrita criativa, concebido por **Formadora - Ana Margarida Fonseca | IA na Educação**, em cocriação com ChatGPT (13 de novembro de 2026).

## Publicação no GitHub Pages

1. Crie um repositório no GitHub (por exemplo, `escrita-criativa-chatgpt`).
2. Carregue o ficheiro **`index.html`** para a raiz do repositório (e, opcionalmente, este `README.md`).
3. Nas definições do repositório, aceda a **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, ramo `main` e pasta `/ (root)`; guarde.
5. Aceda ao endereço apresentado no painel **Pages** quando a publicação estiver disponível.

Pode também abrir `index.html` diretamente no computador. Não é necessária instalação, alojamento adicional ou ficheiros CSS/JS separados.
